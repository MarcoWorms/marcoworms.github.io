# Start your own Chief

Open your signed-in Codex and paste:

> Read https://worms.io/chief/new.md and set up Chief for me.

For Codex: follow the [canonical setup instructions](https://raw.githubusercontent.com/usetempl/chief/main/docs/start.md). Clone [usetempl/chief](https://github.com/usetempl/chief), then create or reuse the person’s separate private workspace. Assume no extra tools are installed; check what the actual OS and session support.

Offer an optional nickname. Use only permitted history, propose the initial board and existing project owners, then begin authorized work. Keep the existing Chief if one already exists.

The core is instructions and Markdown. Telegram is optional and has its own setup. A fresh instance inherits no accounts, credentials, history, project owners or access from the publisher.
