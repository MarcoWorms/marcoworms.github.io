# Chief

Chief uses your existing Codex to organize requested work, reuse project owners and keep a private task board.

Start in your signed-in Codex. The core needs instructions, plain files and the tools already available in that session. It needs no separate model server, Python or CLI. The setup guide checks missing tools before cloning the pack.

Paste this to begin:

> Read https://worms.io/chief/new.md. Clone the public instruction pack and set up my own private Chief. Assume no Git, Python, CLI or package manager. Offer an optional nickname, use only history I permit, propose my board and existing owners, then begin my authorized work.

Keep “Chief,” choose a nickname, or ask for a suggestion from consented history. First success is a corrected project list and board, followed by one authorized task with a checked result. Missing history or owner tools must remain explicit.

| Guide | Use it to |
| --- | --- |
| [Start your own Chief](new.md) | Create an independent private workspace from your signed-in Codex. |
| [Core instructions](core.md) | Maintain one owner per project and a `backlog / todo / doing / review / done` board. |
| [How Chief works](map.md) | Follow a request from access checks to its project owner, board and reply. |
| [Connect another device](device.md) | Request verified enrollment with your existing Chief. |
| [Use Dot](dot.md) | Relay through an already authenticated connection, where available. |

Your identity, board and optional bot belong to you. Nothing here grants access to Alfred or another person's Chief. Public interface instructions are not device approval, credentials or invitations.

This pack contains instructions only. Runtime helpers and Alfred's Telegram/device adapters remain private and are not publicly installable from this repository. Recurrence records a next run but needs a separately authorized scheduler or a user request to execute. The guides do not establish native Linux app availability or verified external-device support.
